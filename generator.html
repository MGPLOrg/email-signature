Arth email signature generator

Fill in the details and choose a photo. The signature is built from images, so it looks the same in light and dark mode, on web and in the Gmail apps.

A round cut-out exported from Figma is used as is; any other photo is cropped to a circle (adjust it with the sliders).

Preview

Steps

  1. Fill in the details and choose a photo from the list, or from this device. To add a photo to the list, upload it on GitHub to assets/photos (Add file → Upload files) and reload this page.
  2. Paste a GitHub token once (tick Remember to skip this next time).
  3. Click Copy signature. If the photo or details changed, the page first uploads the new images to assets/email/people/shikhar-parekh/ and waits until they are online (about a minute), then copies. Gmail loads the pictures from there, so they must be online first.
    No token? Use Download the 4 images, upload them to that folder on GitHub by hand, wait a minute, then click Copy.
  4. Paste into Gmail → Settings → Signature, replacing the old one, and save.
