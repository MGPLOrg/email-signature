Arth email signature generator

Fill in the details and choose a photo. Copy signature copies exactly what the preview shows, straight away. The signature is made entirely of pictures, so it stays white in dark mode in Gmail on computer and phone.

To add a photo, upload it on GitHub to assets/photos (Add file → Upload files), wait a minute and reload this page. Use a square photo cropped close to the face, or a round cut-out exported from Figma; GitHub turns it into the round signature photo automatically.

Preview

Steps

  1. Type the details and choose the photo.
  2. Click Copy signature.
  3. In Gmail open Settings → See all settings → Signature, paste it in place of the old one and click Save changes at the bottom.
